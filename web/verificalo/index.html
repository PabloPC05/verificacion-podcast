Verifícalo tú

Esta verificación la han hecho modelos de IA y no la ha revisado un equipo de periodistas. No hace falta que te la creas: todo está publicado para que lo compruebes a mano, con los datos de la API o con tu propia IA.

  1. 1

    Mira el momento exacto

    En la línea temporal, el minuto de cada afirmación abre el vídeo de YouTube en ese segundo. Escucha la frase y su contexto.

  2. 2

    Abre las fuentes

    Cada panel lista las fuentes con su enlace. «Explicación completa» detalla qué dato sale de cada una.

  3. 3

    Pásaselo a una IA

    Cada panel tiene un botón que copia un encargo para esa afirmación concreta. Para auditar una entrevista entera, usa el encargo de abajo.

  4. 4

    Consulta la API

    Afirmaciones, veredictos, fuentes y transcripciones, en JSON y CSV, sin clave. Está aquí abajo, con ejemplos para hoja de cálculo, terminal y programación. El método y los encargos originales, en GitHub.

API abierta

Todos los datos de la web están en una API pública de solo lectura, en JSON y CSV, sin registro ni clave y con CORS abierto. Se puede consultar desde el navegador, una hoja de cálculo, la terminal o cualquier programa.

Ejemplos

Hoja de cálculo. En Google Sheets, pega esto en una celda para cargar todas las afirmaciones:

=IMPORTDATA("https://verificacion-podcast.vercel.app/api/v1/afirmaciones.csv")

En Excel: Datos → Obtener datos → Desde la web y pega la dirección del CSV.

Terminal. Las afirmaciones falsas de una entrevista, con sus fuentes:

curl -s https://verificacion-podcast.vercel.app/api/v1/sanchez.json \
  | jq '.afirmaciones[] | select(.veredicto == "falso") | {minuto, cita, resumen, fuentes}'

Python.

import json, urllib.request

url = "https://verificacion-podcast.vercel.app/api/v1/afirmaciones.json"
datos = json.load(urllib.request.urlopen(url))
for a in datos["afirmaciones"]:
    if a["veredicto"] in ("falso", "enganoso"):
        print(a["invitado"], a["minuto"], a["veredicto"], a["afirmacion"])

JavaScript.

const r = await fetch("https://verificacion-podcast.vercel.app/api/v1/entrevistas.json");
const { entrevistas } = await r.json();
entrevistas.forEach(e => console.log(e.invitado, e.por_veredicto));

Una IA también se equivoca: pídele siempre los enlaces y ábrelos. Si su respuesta contradice un veredicto con una fuente sólida, abre una incidencia con el identificador de la afirmación y lo corregimos.



Qué significa cada veredicto




Leyenda


El color del minuto, del punto de la línea y de la etiqueta indica el veredicto de cada afirmación.




Falso
Los datos lo contradicen. Incluye errores y lapsus: no implica intención de mentir.


Engañoso
Parte de un dato real, pero confunde. Omite contexto, mezcla periodos o lleva a una conclusión que no se sigue.


Casi cierto
Cierto en lo esencial. Tiene una imprecisión menor, como un redondeo o una fecha aproximada.


Verdadero
Los datos lo confirman.


No verificable
Sin prueba pública suficiente. No se puede confirmar ni desmentir, o la búsqueda automática se quedó corta.
