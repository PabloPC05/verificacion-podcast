API abierta para comprobar la verificación

Todos los datos de esta web están disponibles como JSON estático: sin clave, sin límite propio de uso y con CORS abierto. Está pensada para que periodistas, verificadores y agentes de IA puedan revisar cada veredicto contra sus fuentes mucho más rápido que leyendo la web.

Direcciones

QuéDirección
Lista de entrevistas, recuentos y temas (empieza aquí)/api/v1/entrevistas.json
Todas las afirmaciones de todas las entrevistas/api/v1/afirmaciones.json
Afirmaciones de una entrevista/api/v1/{slug}.json
Transcripción por segmentos con tiempos/api/v1/{slug}/transcripcion.json
Transcripción en texto plano/api/v1/{slug}/transcripcion.txt
Descripción OpenAPI 3.1/api/v1/openapi.json
Guía para modelos de lenguaje/llms.txt

Entrevistas disponibles (slug): sanchez, feijoo.

Qué trae cada afirmación

CampoContenido
idIdentificador estable: entrevista y segundo del vídeo.
citaLo que se dijo, literal de la transcripción.
afirmacionLa afirmación reformulada para que se entienda sola.
veredictoverdadero, mayormente_verdadero, enganoso, falso o no_verificable.
resumen, explicacionLa justificación, en una frase y completa.
confianzaalta, media o baja.
fuentesLista de {titulo, url} que sustentan el veredicto.
segundo, minuto, video_urlEl momento exacto del vídeo.
tema, tema_nEl capítulo de la entrevista.
web_urlEnlace a la tarjeta en esta web.

Ejemplos

# Las afirmaciones falsas de una entrevista, con sus fuentes
curl -s https://verificacion-podcast.vercel.app/api/v1/sanchez.json \
  | jq '.afirmaciones[] | select(.veredicto == "falso") | {minuto, cita, resumen, fuentes}'

# Recuento por veredicto de todas las entrevistas
curl -s https://verificacion-podcast.vercel.app/api/v1/entrevistas.json | jq '.entrevistas[] | {invitado, por_veredicto}'

Encargo para un agente de IA

En Verifícalo tú hay un encargo completo, configurable por entrevista, que usa esta API para auditar los veredictos.

Condiciones

Los datos son una verificación asistida por IA, sin revisión de un equipo de periodistas: úsalos como punto de partida y contrasta con las fuentes. «Falso» no implica intención de mentir. Los ficheros se regeneran cuando cambia algún dato (campo generado). Si encuentras un error, abre una incidencia en GitHub; el método completo está en METODO.md.
